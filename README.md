# BetterRails

更好的铁轨是一个 Slimefun 附属插件，添加了两条并行路线的高速动力铁轨。

## 功能

- 原版材料路线：适合更偏向原版生存的玩家。
- 粘液科技合金路线：适合已经深入 Slimefun 科技线的玩家。
- 所有铁轨均为动力铁轨，放置后矿车经过会获得更高最大速度。
- 作者：happy
- 仓库：https://github.com/happy66dev/BetterRails

## 原版材料路线

| 物品 | 速度 |
| --- | --- |
| 铜质动力铁轨 | 2x |
| 铁质动力铁轨 | 3x |
| 金质动力铁轨 | 4x |
| 钻石动力铁轨 | 5x |
| 下界合金动力铁轨 | 6x |

## 粘液科技合金路线

| 物品 | 速度 |
| --- | --- |
| 钢制动力铁轨 | 2x |
| 大马士革钢动力铁轨 | 3x |
| 硬化金属动力铁轨 | 4x |
| 强化合金动力铁轨 | 5x |
| 黑金动力铁轨 | 6x |

## 构建

```bash
mvn clean package
```

构建完成后，将 `target/BetterRails.jar` 放入服务器 `plugins` 文件夹，并确保已安装 Slimefun。
